# Money_Tracker
Трекер для учета финансовых операций. Стек используемых технологий: Python 3.9.3, Aiogram 3.22, Psycopg2 2.9.12, dotenv.

### Использование бота в своих целях
1. Устаноите все файлы из репозитория
2. Создайте файл с именем `.env` в корневой папке проекта Это необходимо для запуска бота.
3. Зайдите в телеграм и найдите бота с именем `BotFather`. Создайте нового бота.
4. При помощи файла конфигурации базы данных, создайте БД.
5. Перейдите в файл `.env`, создайте переменную `TOKEN` присвойте ей токен, полученный при создании нового бота. Переменные кофигурации базы данных: 
  ```env
  DB_host = ""
  DB_user = ""
  DB_password = ""
  DB_port = ""
  DB_name = ""
  ```
  В двойных ковычках необходимо указать параметры для подключения к БД.
6. Запустите файл run.py командой `python3 run.py`
