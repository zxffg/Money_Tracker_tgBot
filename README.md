# Money_Tracker
Трекер для учета финансовых операций. Стек используемых технологий: Python 3.9.3, Aiogram 3.22, Psycopg2 2.9.12, dotenv.
### Version's
#### 1.0
Был добавлен базовый функционал. 
Добавление реализованно через выбор одной из популярных категорий или создания новой. Удаление работает через выбор одной из пяти последних записей. Просмотр текущего баланса.

### 1.1
Исправление ошибок:
* Исправлено форматирование текста, добавлено больше информации (Например: при добавлении новой записи, у старых категорий отображается тип операции)
* Добавлена проверка чисел при добавлении новой записи
* Добавлена проверка ввода названий категорий. Не более 50-ти символов. Вводимое значение приводится к единому формату (первая заглавная буква)
* Добавлен роутер обработки глобальных ошибок, для обеспечения устойчивой работы бота.
